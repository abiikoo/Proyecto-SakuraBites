## Descripción

**Sakura Bites** es un sistema web desarrollado para la gestión de un food truck especializado en comida asiática (japonesa, coreana, etc.).

La plataforma permite a clientes y administradores interactuar con el sistema mediante funcionalidades como pedidos, gestión de inventario y control del personal.

---

## Objetivos del Proyecto

- Mejorar la organización del negocio  
- Automatizar procesos de pedidos e inventario  
- Brindar una experiencia moderna al usuario  
- Permitir el seguimiento de ventas y operaciones  

---

## Funcionalidades

### 👤 Cliente
- Registro e inicio de sesión  
- Visualización del menú  
- Agregar productos al carrito  
- Realizar pedidos  
- Ver historial de pedidos  

### 🛠️ Administrador
- Gestión de inventario  
- Gestión de empleados  
- Control y procesamiento de pedidos  
- Gestión de horarios  
- Panel administrativo

El sistema está basado en un **modelo de base de datos relacional**, que incluye:

- Usuarios (roles: administrador / cliente)  
- Pedidos  
- Productos  
- Inventario  
- Empleados
